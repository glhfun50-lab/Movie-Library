## Описание программы

**Movie Library** — графическое приложение для хранения информации о фильмах.  
Позволяет добавлять фильмы с названием, жанром, годом выпуска и рейтингом, фильтровать их по жанру и году, сохранять и загружать данные через JSON-файл.

Поддерживаемые жанры: Драма, Комедия, Боевик, Фантастика, Ужасы, Мультфильм, Детектив, Романтика, Документальный, Другое.

## Как пользоваться

1. **Добавление фильма:**  
   - Введите название  
   - Выберите жанр из списка  
   - Укажите год выпуска (число от 1888 до текущего года + 5)  
   - Введите рейтинг от 0 до 10 (например, `7.5`)  
   - Нажмите **«Добавить фильм»**

2. **Фильтрация:**  
   - Выберите жанр или оставьте «Все»  
   - Укажите диапазон лет (поля «Год от» и «Год до»)  
   - Нажмите **«Применить фильтр»**  
   - Для сброса фильтров — кнопка **«Сбросить»**

3. **Удаление записи:**  
   - Выделите строку в таблице  
   - Нажмите **«Удалить выбранное»**

4. **Итоговая статистика** внизу показывает количество фильмов и средний рейтинг по фильтру.

## Тестирование

### Ручное тестирование

| Тип теста | Действие | Ожидаемый результат |
|-----------|----------|---------------------|
| Позитивный | Ввод названия, жанр «Боевик», год `1994`, рейтинг `8.6` | ✅ Фильм добавлен |
| Позитивный | Ввод года `1888` (первый фильм) | ✅ Принято |
| Негативный | Пустое название | ❌ Ошибка: «Введите название фильма» |
| Негативный | Год `abc` | ❌ Ошибка: «Год должен быть числом» |
| Негативный | Год `1800` | ❌ Ошибка: «Год должен быть в диапазоне...» |
| Негативный | Рейтинг `15` | ❌ Ошибка: «Рейтинг должен быть от 0 до 10» |
| Негативный | Рейтинг `-2` | ❌ Ошибка: «Рейтинг должен быть от 0 до 10» |
| Граничный | Рейтинг `0` | ✅ Принято |
| Граничный | Рейтинг `10` | ✅ Принято |

### Unit-тесты

В проекте есть файл `test_movie_library.py` с автоматическими тестами для функций валидации и фильтрации.  
Запуск тестов:

```bash
python -m unittest test_movie_library.py
```

Тесты проверяют:
- Валидацию года (корректные и некорректные значения)
- Валидацию рейтинга (0–10, поддержка запятой)
- Фильтрацию по жанру
- Фильтрацию по диапазону лет
